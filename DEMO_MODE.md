# InsightFC Demo Mode

Visit `/demo` in the preview deployment.

This is a UI-only sandbox with fictional U10 data. It does not write demo teams, players, games, or events to Supabase.

Included demo concepts:
- coach dashboard
- team/roster
- player profiles
- game analysis timeline
- highlights/full game placeholders
- goals, assists, shots, passes, carries (10+ yards), take-ons, pressures, possession won

The demo is intentionally separate from production data.
